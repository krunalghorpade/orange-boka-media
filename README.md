# Orange Boka Media

A lightweight, mobile-first website built with HTML, CSS and JavaScript. The website files live at the repository root.

## Preview

Run `npm run dev` from this directory and open http://127.0.0.1:4173.

Edit the pages here: `index.html`, `music.html`, `artist.html`, `services.html`, `pricing.html`, and `contact.html`. Shared styling is in `styles.css`; interactions are in `app.js`; logo files are in `assets/`.

Run `npm run build` to generate `dist/` for the existing Sites deployment. Generated files are not committed to GitHub.

## Design and behavior

- Helvetica Neue with Helvetica and Arial system fallbacks.
- Original supplied logo assets; SVG body and animated eyes bring the mascot to life.
- Pointer / touch tracking, reduced-motion support, and animation suspended off screen.
- Separate home, music promotion, artist presence, services, pricing and contact pages.
- Friendly, problem-focused homepage with only an inline entry price.
- ₹999 Fresh Ears artist-profile and release audit; detailed package scopes live on the pricing page.
- Music PR through owned meme pages and influencers, with campaign scope quoted separately.
- Keyboard-accessible pricing tabs and expandable package scopes.
- All enquiries open the visitor's email client addressed to business@orangeboka.in. There is no form backend or customer data collection.
- Supplied prices, scope, exclusions and three-month retainer minimum retained.

Run `npm run check` to verify JavaScript syntax.
